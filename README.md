# Bank Customer Churn Analysis
Analysis of 10,000 Bank Customers' Churn Data using SQL, Python and Tableau for visualisation to identify key drivers why customers are leaving.

## Business Problem
The bank is losing customers and wants to know who leaves and why.

## Key Insights
- Overall churn rate: 20.4%
- Germany has the highest churn (32%) vs France (16%)
- Inactive members are far more likely to leave

## Recommendations
- Launch re-engagement campaigns for inactive members
- ...

## Tools
SQL (MySQL), Python (pandas, seaborn), Tableau
